# Руководство пользователя

VoiceScribe — полностью офлайн-приложение для транскрипции речи в текст. Всё распознавание выполняется на устройстве: аудио не покидает телефон, интернет нужен только для скачивания моделей.

## Установка

1. Установите APK (`adb install -r app-debug.apk` или скопируйте файл на устройство и откройте его).
2. Первый запуск может занять время — приложение инициализирует базу данных и проверяет установленные модели.
3. **Разрешите уведомления** для VoiceScribe (Настройки → Приложения → VoiceScribe → Уведомления). Без этого не будет виден прогресс транскрипции в фоновом режиме.

## Первая настройка: скачивание моделей

До транскрипции нужно скачать модели на вкладке **«Модели»**:

| Модель | Назначение | Размер |
|---|---|---|
| Whisper tiny / base / medium | Распознавание речи (ASR). tiny — быстрее, medium — точнее | ~39 МБ / ~74 МБ / ~1.9 ГБ |
| Silero VAD v5 | Детекция речи/тишины (фильтрация пауз) | ~2.3 МБ |
| pyannote-segmentation-3-0 | Диаризация: поиск говорящих | ~1.5 МБ |
| 3D-Speaker ERes2Net | Эмбеддер для диаризации | ~39.6 МБ |

Порядок действий:

1. Откройте вкладку **«Модели»**.
2. Нажмите **«Скачать»** у нужных моделей. Минимум для транскрипции — одна Whisper-модель. Для диаризации нужны pyannote + 3D-Speaker.
3. После завершения скачивания и проверки SHA-256 модель получит статус **«Активна»** (или активируйте её кнопкой).
4. **«Удалить»** — удаляет файлы модели; активную модель удалить нельзя (сначала активируйте другую).

> Модели хранятся во внутреннем хранилище приложения (`filesDir/models`) и распаковываются автоматически (архивы tar.bz2). Названия файлов в архивах могут отличаться от документации — приложение ищет их по префиксу модели.

## Транскрипция

1. Вкладка **«Транскрипция»** → кнопка выбора аудиофайла.
2. Настройте параметры:
   - **VAD-фильтрация** (вкл. по умолчанию) — вырезает тишину, речь нарезается на сегменты ~20 с. При выключении файл режется на фиксированные чанки по 30 с.
   - **Диаризация** (выкл. по умолчанию) — определение говорящих (нужны модели pyannote + 3D-Speaker).
   - **Язык** — выберите из списка или оставьте **«Авто»** (определение внутри Whisper).
3. Нажмите **«Транскрибировать»**. Задача уходит в фоновый сервис:
   - в списке задач появится карточка с этапом и процентом (Подготовка → Декодирование → VAD/диаризация → Распознавание);
   - прогресс дублируется в уведомлении.
4. Задачу можно **отменить** (кнопка на карточке или из уведомления).
5. По завершении карточка становится кликабельной → открывается транскрипт.

## Просмотр транскрипта

На экране транскрипта:

- **Метаданные**: дата, параметры (VAD/диаризация/язык).
- **Сегменты** с текстом; при диаризации у каждого сегмента есть цветной чип спикера.
- **Переименование спикера** — тап по чипу спикера → ввод имени.
- **Поиск по тексту** — поле поиска с задержкой; результаты подсвечиваются (FTS-индекс).
- **Экспорт** — меню в шапке: TXT, SRT, VTT или JSON. Системный диалог выбора места сохранения (SAF).

## Приватность

- Приложение не отправляет ничего в сеть, кроме скачивания моделей с k2-fsa GitHub releases.
- Нет телеметрии, аналитики, Firebase.
- Транскрипты хранятся только в локальной базе Room.

## Ограничения

- Распознавание только на CPU (ARM NEON); GPU/NNAPI/Vulkan не поддерживаются.
- При наложении речи (до 3 говорящих модель может их различать) в транскрипте сохраняется только доминирующий спикер.
- Экзотические контейнеры (MKV/WEBM с нестандартными аудиодорожками) могут не декодироваться.
- Whisper medium — ~1.9 ГБ, для скачивания нужен стабильный интернет; распознавание на телефоне медленнее маленьких моделей.
