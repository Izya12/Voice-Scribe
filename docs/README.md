# Документация VoiceScribe

VoiceScribe — офлайн-транскрибатор речи для Android (Whisper ASR через sherpa-onnx). Документация разделена на пользовательскую и техническую части.

## Содержание

| Документ | Для кого | О чём |
|---|---|---|
| [README.md](../README.md) | Все | Обзор проекта, возможности, сборка |
| [Руководство пользователя](user-guide.md) | Пользователи | Установка, первая настройка, транскрипция, экспорт |
| [Руководство разработчика](developer-guide.md) | Разработчики | Модули, сборка, пайплайн, тесты, конвенции |
| [Устранение неполадок](troubleshooting.md) | Все | Типичные проблемы и их решение |

## Канонические документы (корень репозитория)

Эти файлы — источник истины по архитектуре и состоянию проекта:

- **RESEARCH.md** — исследовательская фаза (Phase 1): выбор движка, форматов, ограничений.
- **ARCHITECTURE.md** — спецификация системной архитектуры (Phase 2), **заморожена**: авторитетна, не редактировать без веской причины.
- **PROJECT_MANIFEST.md** — состояние проекта, версии, каталог моделей с SHA-256, статус тестов.

## Структура репозитория

```
├── core/model/    # доменные модели, машина состояний JobState
├── core/domain/   # интерфейсы, use cases, ошибки
├── engine/        # адаптеры sherpa-onnx (Whisper, VAD, диаризация, язык)
├── data/          # Room DB, декодирование/ресемплинг аудио, скачивание моделей, экспорт
├── app/           # Compose UI, Hilt, MediaProcessingService (FGS)
└── docs/          # эта документация
```
